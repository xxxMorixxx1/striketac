# Инструкция: Бесплатный запуск сервера на Glitch.com (без карт и без Docker)

Glitch.com — один из самых простых и дружелюбных бесплатных хостингов для Node.js. 
Он не требует Docker, не требует кредитных карт и сразу выдает постоянный адрес с HTTPS и WebSockets.

---

### Шаг 1. Создать проект на Glitch
1. Перейдите на сайт [glitch.com](https://glitch.com) и войдите (кнопка **Sign In** через Google или Email).
2. Нажмите синюю кнопку **New Project** (справа вверху).
3. В выпадающем списке выберите **glitch-hello-node** (готовый базовый Node.js сервер).

---

### Шаг 2. Задать красивое имя проекту
В левом верхнем углу кликните по случайному имени проекта (например, quiet-fluffy-cat) и замените его на свое, например:
striketac-game (или любое свободное имя).

Ваш постоянный адрес сервера будет:
👉 https://ВАШЕ_ИМЯ.glitch.me

---

### Шаг 3. Загрузить файлы StrikeTac

#### Способ 1: Импорт с GitHub (самый простой)
1. Внизу слева нажмите кнопку **Tools** ➔ **Import and Export**.
2. Нажмите **Import from GitHub**.
3. Вставьте ссылку на ваш репозиторий (например: https://github.com/ВАШ_ЛОГИН/striketac) и нажмите OK.
4. Glitch за 10 секунд скачает код и сам всё запустит!

#### Способ 2: Загрузка файлов вручную
1. В левом меню Glitch нажмите кнопку **+ Add File** ➔ **Upload a File**.
2. Загрузите файлы из папки 	sest:
   - server.js
   - kmz-parser.js
   - package.json
   - glitch.json
   - Файлы из папки public/
3. Внизу в меню **Logs** вы увидите запуск: ⚡ StrikeTac Airsoft Tactical Server запущен!.

---

### Шаг 4. Подключение телефонов
1. На телефонах откройте приложение **StrikeTac.apk**.
2. В правом верхнем углу нажмите кнопку **🌐 СЕРВЕР**.
3. Вставьте адрес вашего Glitch:
   https://ВАШЕ_ИМЯ.glitch.me
4. Нажмите **«Сохранить»**.

Сервер будет работать в интернете постоянно и бесплатно!
