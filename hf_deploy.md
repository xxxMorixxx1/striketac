# Пошаговая инструкция: Запуск StrikeTac на Hugging Face Spaces (Бесплатно 24/7)

Hugging Face Spaces предоставляет **бесплатный облачный сервер 24/7** (16 ГБ RAM, 2 vCPU), без привязки карт, без смс и без блокировок в РФ.

---

### Шаг 1. Создать Space на Hugging Face
1. Откройте сайт [huggingface.co](https://huggingface.co) и войдите (или зарегистрируйтесь через email / Google).
2. Нажмите на иконку своего профиля справа вверху ➔ выберите **New Space** (или перейдите по ссылке: https://huggingface.co/new-space).
3. Заполните поля:
   - **Space name**: striketac (или любое название)
   - **Space SDK**: выберите **Docker** (шаблон: **Blank**)
   - **Space hardware**: оставьте бесплатный (**CPU basic · 2 vCPU · 16GB · Free**)
   - **Visibility**: **Public**
4. Нажмите кнопку **Create Space**.

---

### Шаг 2. Загрузить файлы проекта
После создания Space перед вами откроется страница репозитория.

#### Вариант через браузер (без команд):
1. Вверху перейдите на вкладку **Files** (Файлы).
2. Нажмите **Add file** ➔ **Upload files**.
3. Перетащите в окно браузера следующие файлы и папки из вашей папки `tsest`:
   - `Dockerfile`
   - `README.md`
   - `package.json`
   - `package-lock.json`
   - `server.js`
   - `kmz-parser.js`
   - Папку `public`
4. Внизу нажмите кнопку **Commit changes to main**.

#### Либо вариант через терминал (Git):
```bash
git remote add hf https://huggingface.co/spaces/ВАШ_ЛОГИН/striketac
git push -u hf master:main -f
```

---

### Шаг 3. Получить постоянный адрес сервера
1. Hugging Face автоматически запустит сборку Docker (займет ~30-40 секунд).
2. Когда статус сменится на зеленый **Running**:
   - В правом верхнем углу нажмите меню из трех точек ... ➔ **Embed this Space**.
   - Там будет прямая ссылка вида:
     https://ВАШ_ЛОГИН-striketac.hf.space
   *(Также можно просто скопировать этот URL: имя_пользователя-имя_space.hf.space)*.

---

### Шаг 4. Подключить телефоны
1. На смартфонах откройте приложение **[StrikeTac.apk](file:///c:/Users/Administrator/Desktop/tsest/StrikeTac.apk)** (или откройте ссылку в браузере любого телефона).
2. В правом верхнем углу нажмите кнопку **🌐 СЕРВЕР**.
3. Вставьте вашу ссылку: https://ВАШ_ЛОГИН-striketac.hf.space и нажмите **«Сохранить»**.

Готово! Теперь сервер работает **постоянно 24/7 в облаке**, полностью бесплатно, и ПК держать включенным не нужно.
