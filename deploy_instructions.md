# Инструкция: Бесплатный запуск сервера StrikeTac в облаке (24/7 без ПК)

Чтобы страйкбольный сервер работал **полностью автономно без включенного компьютера**, серверная часть выгружается на бесплатный облачный хостинг (например, **Render.com** или **Koyeb**).

---

## Вариант 1: Развертывание на Render.com (3 минуты, бесплатно)

Render.com предоставляет бесплатный хостинг для Node.js приложений с автоматическим HTTPS и WebSocket.

### Шаг 1. Загрузите проект на GitHub
1. Откройте [GitHub](https://github.com) и войдите в свой аккаунт (или зарегистрируйтесь).
2. Нажмите **New repository** (Новый репозиторий). Назовите его, например, striketac (можно сделать Public или Private).
3. В папке проекта на компьютере выполните команды:
   `ash
   git remote add origin https://github.com/ВАШ_ЛОГИН/striketac.git
   git branch -M main
   git push -u origin main
   `

### Шаг 2. Запуск в Render
1. Перейдите на [Render.com](https://render.com) и зарегистрируйтесь через GitHub.
2. В панели управления нажмите кнопку **New +** -> **Web Service**.
3. Выберите ваш репозиторий striketac из списка.
4. Render автоматически считает файл ender.yaml из репозитория! Либо укажите параметры вручную:
   - **Name**: striketac
   - **Language**: Node
   - **Build Command**: 
pm install
   - **Start Command**: 
ode server.js
   - **Instance Type**: Free
5. Нажмите **Create Web Service**.
6. Через 1-2 минуты сервис запустится и выдаст вам постоянную бесплатную ссылку, например:
   https://striketac.onrender.com

---

## Вариант 2: Запуск на Koyeb (без засыпания, бесплатно)

1. Зарегистрируйтесь на [Koyeb.com](https://www.koyeb.com).
2. Нажмите **Create App** -> **GitHub** -> выберите репозиторий striketac.
3. Тип сервиса: **Web Service**, тариф: **Free**.
4. Порт: 3000.
5. Нажмите **Deploy**.
6. Вы получите постоянную ссылку вида: https://striketac-xxx.koyeb.app.

---

## Как подключить телефоны и APK к облачному серверу

1. Установите файл **StrikeTac.apk** на смартфон.
2. Запустите приложение.
3. В окне входа нажмите кнопку **🌐 СЕРВЕР** в правом верхнем углу.
4. Вставьте вашу ссылку на облачный сервер (например: https://striketac.onrender.com) и нажмите **«Сохранить»**.
5. Адрес сохранится в памяти телефона навсегда.

Теперь сервер работает **24/7 в облаке**, игроки с любыми смартфонами (Android / iPhone) могут заходить в игру из любой точки полигона через мобильный интернет!
